# Superseded — the privacy policy is a page now

The draft that was here became `src/app/privacy/page.js` in v1.61.0, live at
[getturnup.com/privacy](https://www.getturnup.com/privacy) and linked from the
homepage footer.

It moved because the ServiceM8 listing field takes a **URL**, not a document,
and because two copies of the same policy drift apart within a week — which is
the whole reason Standing Rule 24 exists.

Change the page, not this file. If a line on it and the code ever disagree, the
line is the bug.
